Deepsight Site ​

site/ 是 Deepsight 官网与文档站的独立前端工程，基于 VitePress 构建。

常用命令 ​

bash
cd site
npm install
npm run docs:dev
npm run docs:build

维护原则 ​

  • 文档真源在根目录 docs/
  • 官网首页在 site/index.md
  • site/guide/ 由脚本生成，不要手动改
  • 发布流程见 docs/dev/site.md
